# Symbiotek Website - Deployment Instructions

## Tech Stack
- React 18 + Vite 6
- bloom-menu (iOS-inspired pull-down menus)
- framer-motion (animations)
- GitHub Pages deployment via gh-pages branch

## Making Updates & Deploying

### Step 1: Make Code Changes
Edit files in the `src/` directory as needed:
- `src/components/` - React components
- `src/App.css` - Global styles
- `src/utils/animations.js` - Animation configurations

### Step 2: Test Locally
```bash
# Start development server
npm run dev

# Visit http://localhost:5173
# Test your changes
# Press Ctrl+C to stop server when done
```

### Step 3: Commit Changes to Git
```bash
# Stage your changes
git add .

# Commit with a descriptive message
git commit -m "Description of your changes"

# Push to GitHub
git push
```

### Step 4: Deploy to GitHub Pages
```bash
# Build and deploy to gh-pages branch
npm run deploy
```

This command will:
1. Build the production version (runs `vite build`)
2. Push the built files to `gh-pages` branch
3. GitHub Pages will automatically serve the new version

### Step 5: Verify Deployment
- Wait 1-2 minutes for GitHub Pages to update
- Visit: https://symbio-tek.com
- Check that your changes are live

## GitHub Pages Configuration

**Settings Location:** https://github.com/KG191/SymbioTek/settings/pages

**Current Setup:**
- Source: Deploy from a branch
- Branch: `gh-pages`
- Folder: `/ (root)`

## Important Notes

- Always test locally with `npm run dev` before deploying
- The `main` branch contains source code
- The `gh-pages` branch contains built files (auto-generated by `npm run deploy`)
- Custom domain: symbio-tek.com (configured via public/CNAME)
- Build size: ~90KB gzipped

## Component Locations

- **Header:** `src/components/Header/Header.jsx` (navigation with bloom-menu)
- **Hero:** `src/components/Hero/Hero.jsx` (main section with animations)
- **Mission:** `src/components/Mission/Mission.jsx` (mission cards with stagger animation)
- **Apps:** `src/components/Apps/Apps.jsx` & `AppCard.jsx` (app cards with bloom-menu)
- **Contact:** `src/components/Contact/Contact.jsx`

## Troubleshooting

### Issue: Changes not showing on live site
- Solution: Run `npm run deploy` again and wait 1-2 minutes

### Issue: Build errors
- Solution: Check console for errors, fix them, then redeploy

### Issue: npm commands not working
- Solution: Run `npm install` to ensure all dependencies are installed
